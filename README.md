# Yamaha Tenere 700 (2025+) CCU CAN Bus Specification

2025年式 ヤマハ テネレ700（Euro5+ / 新型6.3インチTFTメーター / YCC-T世代）の CCU（コミュニケーションコントロールユニット）コネクタから観測した CAN 通信プロトコルの独自解析ドキュメントおよび DBC ファイルです。

An independent, community-driven CAN bus protocol specification and DBC definition for the **2025+ Yamaha Tenere 700** (Euro5+ / 6.3-inch TFT / YCC-T generation), observed via the CCU (Communication Control Unit) connector.

## Overview / 通信概要

* **Tap Point / 接続ポイント**: CCU コネクタ Y分岐（Listen-Only / 終端抵抗なし）
* **Architecture / 共通アーキテクチャ**: 2025年世代 ヤマハ新電装プラットフォーム（YZF-R9 / MT-07 / Tenere 700 共通ID体系）
* **Endianness / バイト順**: Big Endian（上位バイト先頭）、`Byte 0` 始まり
* **Current Status / 解析ステータス**:
  * 停車・ベンチテスト（キーON、クランキング、アイドリング、空ぶかし、スタンド・ギア操作）および CCU 連携操作（ナビ・電話・メッセージ）に基づく解析結果です。
  * 実走行時の車速、前後輪速、ABS/TCS介入、走行モード切替、燃料残量変化の詳細は未検証（プレースホルダとして定義済み）です。

## Implementation Notes / 実装メモ

* **左右ウィンカー信号**: CCU 側 CAN バスには出力されません（左スイッチボックス〜TFTメーター〜フラッシャー回路間で完結）。
* **燃費情報の取得**: 外部から診断リクエストを送信しなくても、CCU が約 0.5 秒周期で `7E0#02 21 01` を自発的にポーリングしています。Listen-Only で `0x7E8` のマルチフレーム応答を傍受することで、積算燃料消費カウンター（`22`フレーム Byte 4）およびインジェクター噴射パルス幅（`24`フレーム Byte 2–3）を取得できます。
* **Wireshark での利用**: `編集 (Edit) > 設定 (Preferences) > Protocols > CAN DBC` から `yamaha_tenere700_2025_ccu.dbc` を指定すると、キャプチャログ内の各信号が自動的にデコード表示されます。
